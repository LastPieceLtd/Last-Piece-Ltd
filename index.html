Base de données · Importer / enrichir

1. Catalogue CSV

Importez des centaines ou milliers de références. Colonnes : id,name,theme,year,parts,image,model_image,price,buy,sales,growth,retired. Seul id est obligatoire. Les valeurs manquantes restent inconnues. Le fichier doit être en UTF-8 ; séparateur virgule ou point-virgule.

Télécharger le modèle CSV

2. Historique CSV

Importez des observations datées. Colonnes : id,date,price,sales. Une ligne par set et date. price = prix de vente observé (€) ; sales = nombre de ventes durant la période (facultatif). Les sources et les périodes doivent être homogènes.

Télécharger le modèle historique

Les données sont enregistrées dans le navigateur (stockage local), et ne se synchronisent pas entre vous deux. Exportez régulièrement une sauvegarde JSON. Pour une base réellement partagée et mise à jour automatiquement, la prochaine étape sera un stockage centralisé et des connecteurs API autorisés.
